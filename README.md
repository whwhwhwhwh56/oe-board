# Owner Earnings Ledger

Static snapshot of the owner-earnings board (Buffett-1986 owner-earnings valuations,
each number traced to the filing). Built by `oe-db/build_pages.py` from `viewer.html`;
`index.html` holds the board, `d/<TICKER>.json` each ticker's audit trail.
Prices and the 10Y Treasury are as of the stamp on the page — not live.
